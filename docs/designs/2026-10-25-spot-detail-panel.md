# 停車點詳情面板整理

使用者選擇「停車判斷優先，精簡、接近 Google Maps」，並要求一併整理資料 UI。使用 frontend-design 指導，僅調整既有詳情介面與資訊層級。

## 視覺與結構

延續既有海藍主色 #176273、紙白 #F9FBFC、深墨 #16313A，以及與地圖一致的可停綠 #186348、限制琥珀 #865500、不可停紅 #A13042；實際表面與文字跟隨系統深淺色及動態配色。名稱採 24px／600，拉丁文字沿用 Outfit、中文使用平台字體；正文 14–16px，輔助標籤 12–13px。

識別元素是對應地圖形狀與顏色的「停車判斷條帶」，讓資格與限制成為閱讀起點。其餘維持平整分組與細線，避免每項資料都裝進卡片。

```text
  拖曳把手
  停車點完整名稱                       關閉
  類型・地區・距離                收藏／分享
  ┃ 車種・可停判斷
  ┃ 限制與查核提醒
  收費資訊                      格位／剩餘車位
  停車資訊：類型、完整費率、分區與車種
  位置與指引：入口、地址／座標、停放指引、限制
  現場補充：照片與備註
  資料與查核：來源、狀態、更新時間與即時車位時間
  ───────────────────────────
  導航到這裡                  修改建議（固定操作列）
```

名稱只與關閉按鈕共用一列，收藏及分享移至副標操作列。導航與修改建議固定在面板底部，長資料捲動時仍可使用。修改建議直接覆蓋詳情，不再先強制展開父面板。

資料保留四組，沒有資料的入口、停車指引、規則與備註直接省略；必要的資料狀態集中提示，不推測缺少的費率或資格；實際長備註與各分區規則完整顯示。摘要只提供快速判斷，完整資料仍在下方。照片放在現場補充，優先讓騎士閱讀停放與抵達資訊。車種以普通機車、大型重機、汽車圖示呈現，專用與共用明確分開；共用格連接兩個車種圖示。停車場可同時進場不推定共用，未確認分區不繼承其他區的資格。各分區的車種、費率與指引在同一組顯示，地址優先、座標降為輔助文字。

## 行為與驗證

保留半高／全高、拖曳收回、收藏、分享、照片放大、來源連結與修改建議。面板覆蓋底圖，開關不改地圖 padding；選取點的一次相機置中與關閉後保留相機位置維持不變。

驗證手機、窄螢幕、1.6 倍字級與深淺色；檢查長名稱寬度、固定操作列、空白指引省略與必要資料狀態提示、分區費率、零車位與未知車位的區別，以及表單與父面板的關閉流程。截圖自檢通過後更新 PR。

## 共用格位與車種費率

共用描述格位配置，費率是獨立資料。同一個 parking_zones 項目可選填 scooter_fee_note、heavy_fee_note、car_fee_note 字串，與既有 access、fee_note、guide 一起讀寫；資料庫原有 JSONB 可直接容納，不新增欄位或 migration。一般 fee_note 保留完整備註，不自動拆解或複製為車種價格。

專用／共用圖示下方逐一列出普通機車、大型重機或汽車費率，保留原始計費單位與條件。只有一種車種費率時，其他適用車種顯示「費率未提供」；單一分區的頂部摘要跟隨目前車種，多分區顯示依車種與分區計費。舊資料未填此結構時，維持一般費率說明，不推測價格。

例如同一格位共用、各自計費：

```json
{
  "parking_zones": [{
    "name": "共用機車格",
    "access": "scooterHeavy",
    "scooter_fee_note": "20 元／次",
    "heavy_fee_note": "30 元／小時"
  }]
}
```

費率不再於「停車資訊」重複列一個欄位：預覽保留摘要，各車種／分區的價格放在對應圖示下，額外計費條件才另列收費說明。沒有分區費率的舊資料在摘要完整顯示原始費率文字。系統分區標題及預設名稱統一使用「分區」，既有資料自訂的分區名稱保留原文。
