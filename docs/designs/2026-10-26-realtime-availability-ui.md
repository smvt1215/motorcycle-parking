# 即時車位 UI：資格與空位分開呈現

對應 [REALTIME_AVAILABILITY_UI_PLAN.md](../REALTIME_AVAILABILITY_UI_PLAN.md) 的 P0「UI 原型與資料語意」。使用 frontend-design 指導，只擴充既有地圖標記與詳情面板，不改現有資格判斷。設計稿畫布：<https://claude.ai/artifact/KPJ9gVAMG3GbDvYC4pB3Zu>（六張畫板：地圖雙層標記、路外即時、路外延遲與重機無資料、路邊靜態與騎士回報、狀態總表、篩選空結果）。

## 一句話原則

可不可以停，和有沒有位，是兩件事。顏色與形狀只屬於法律資格標記；剩餘數放在中性墨色膠囊裡，兩套狀態永遠不共用顏色。

## 視覺與結構

延續既有色票：海藍 #176273、紙白 #F9FBFC、深墨 #16313A、可停綠 #186348、條件琥珀 #865500、不可停紅 #A13042、待確認灰 #59646C、選取藍 #1A73E8。新增的膠囊只用標記角標既有的墨色 #22282D。拉丁字與數字沿用 Outfit，中文使用平台字體，數字用等寬數字。

### 地圖：膠囊三態

```text
[綠圓 P][剩 12]   填滿墨色膠囊 ＝ 官方即時、資料新鮮
[綠圓 P][◷ 剩 7]  描邊膠囊 ＋ 時鐘 ＝ 更新延遲，數字可能已變
[綠圓 P]          沒有膠囊 ＝ 空位未知（無資料／過期／異常）
[綠圓 P][已滿]    available = 0
[綠圓 P][暫停]    來源標示停止服務
[紅方 ✕][剩 20]   不可停仍是紅色方形，數字照實顯示
[綠圓 P][車 剩 30]  紙白底＋墨色細描邊＋汽車小圖示 ＝ 汽車格剩餘（重機可停，與汽車共用）
```

- **重機剩餘數**（2026-10-26 決定，第一批）：只在有有效重機值的場站顯示；`-9`、缺欄位或重機容量為 0 時不顯示膠囊，也不顯示 0。
- **汽車格剩餘（重機停汽車格）**（2026-10-26 決定，第一批）：目前車種為大型重機，且場站資料已確認重機可停汽車格（`heavyCar`「大型重機與汽車共用」）時才顯示。樣式與重機專用剩餘數分開：紙白底、墨色 #22282D 細描邊、前置汽車小圖示、文字「汽車格 剩 N」，不使用延遲的時鐘描邊樣式。這個數字不能算成重機有位，「目前有位」篩選不採用；詳情寫「汽車格剩餘 N（與汽車共用）・費率依汽車」。未確認的場站不顯示。路邊汽車格圖層另案設計（issue #127）。

膠囊貼在標記右側、略為重疊，高 24、白色 2px 描邊、13px/700。選取放大時膠囊同步放大並維持錨點。群聚圈上的數字仍是停車點數。騎士回報在 15 分鐘內以 16px 人形小角標掛在標記右下，不出現數字。路段線只在有可靠幾何時畫，顏色跟資格。

### 詳情面板

資訊順序不變：名稱、副標、停車判斷條帶、摘要兩欄、固定操作列。變更只在摘要右欄：

- 路外有即時資料：大數字 30px/600 + 「剩餘」+ 「／ 共 80 格」，下方一行「17:02 更新 ・ 臺北市停管處」。
- 路外無本車種資料：「無即時資料」+ 「場站未提供重機或汽車格剩餘」。其他車種的數字以次要列呈現，附延遲註記與「不代表重機可用格數」。
- 路邊靜態：「共 18 格」，「共」與「剩」永遠不同字、不同位置；下方「空位未知 ・ 此路段沒有官方即時資料」。
- 騎士回報：獨立一列，「8 分鐘前有騎士回報『有空位』」+ 「車友目擊，不是官方即時資料；抵達時可能已變。」
- 路邊格新增第三個操作「回報現場狀況」，與「修改建議」並列，導航維持主要。

### 篩選與空結果

「目前有位」只列資料新鮮、車種相符、剩餘大於 0、且可停或有條件可停的點。空結果卡片列出範圍內各點被排除的原因與數量，被篩掉的點在原位改為灰色小圓點（無圖示），讓人知道「不是沒有點，是沒有位」；不用淡灰的完整標記，因為完整標記變淡已用於車友回報已不存在（`reported_gone`）（2026-10-26 使用者決定）。提供「清除『目前有位』」與「只看有即時資訊」。

## 文案規則

- `available = 0` 寫「已滿」，不寫「未知」。
- `null`、`-9`、缺該車種欄位一律「無即時資料」，絕不寫成 0。
- 「暫停營運」與「已滿」分開。
- 延遲狀態保留數字並強制加註「更新延遲 N 分鐘」。
- 社群回報只出現「有騎士回報」字樣，永遠不產生「剩 N」。
- 衝突回報寫「近期回報不一致」，不投票、不平均。

## 與既有程式的接點

- `SpotMarker` 外包可選膠囊；Google Maps 的圖資快取鍵不能把每個數字納入全排列，數字層需增量繪製。
- `availabilitySummary()` 已把負值視為無資料，可延用；新增狀態欄位後改以 `AvailabilitySnapshot.status` 為準。
- `official_heavy_spots` 目前沒有 `available` 欄位；快照寫獨立表，且不得觸發 `bump_data_version('spots')`。
- DESIGN.md「路邊格隱藏即時車位欄」需改為「路邊格顯示總格數與空位未知」，此為刻意變更。

## 待驗證

深淺色、1.6 倍字級下膠囊與大數字的可讀性；VoiceOver／TalkBack 朗讀「官方即時：剩 12 格」與「更新延遲」；放大字級時摘要兩欄改為上下排列；膠囊在密集區域的遮擋順序（資格標記優先，膠囊可省略）。
