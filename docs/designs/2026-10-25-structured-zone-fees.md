# 結構化分區費率

依使用者的照片標註、「結構化分區費率」要求及 Claude 費率交接，接續原生 GitHub Stack #79（#72 → #77 → #75）。點位及分區沿用同一份 `Fee`／`Rate`，支援普通機車與大型重機；大型重機可比照機車或汽車費率，汽車金額不加入本次結構。

每個 `parking_zones` 項目可選填 `fee`，格式與點位級相同。省略車種代表未確認。金額、時間與允許鍵由現有 `valid_fee`、`validFee`、`Fee.fromJson` 共用規則把關；資料表另外檢查每區的巢狀費率。舊 `fee_note` 與各車種費率字串完整保留，沒有結構化資料時才使用，不自動推算或轉換歷史價格。

App 從兩版 community／official viewport 取得點位費率，模型與收藏快照保存點位及分區費率。單區在摘要直接顯示目前車種的實際費率，多區在正文逐區顯示。結構化資料缺少目前車種時顯示未確認，不沿用其他車種、其他分區或場站價格。各車種費率分別呈現，共用格位不代表同價。結構化價格取代舊的重複價格說明。

新增停車點的每區重用 `FeeEditor`，金額驗證加入既有表單，編輯器身分隨分區保持，新增或刪除其他分區不清掉輸入。點位收費修改從既有結構化資料開始，保留未修改車種，不接受完全沒有變更的重送。

驗證涵蓋模型／收藏往返、舊資料相容、單區／多區摘要、未知車種、390／700 px 與放大字級、分區編輯與驗證、Edge Function 的允許／拒絕案例，以及資料庫實際寫入、兩版 viewport 的讀取、RLS 及巢狀費率約束。既有價格轉換仍依原決策排在 Admin Web P6，不在本次自動改寫資料。

管理站費率編輯依交接約定等 #76、#77 合併後接入（兩者已合併，管理站費率實作中）；位置、地址搜尋與全點位地圖仍由 Claude 的非費率工作負責。
