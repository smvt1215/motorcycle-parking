# App UI 截圖自檢

390 × 844 邏輯像素，Android／iOS、深淺色，共 32 張畫面；每張圖組由左到右、由上到下呈現八個狀態：

1. 放大的數字「6」停車點群聚圈（56dp；定位藍點維持原尺寸）。
2. 車種面板直接疊在底圖，底圖位置與尺寸保持不變。
3. 精簡預覽：名稱保留完整寬度、停車判斷與收費摘要，底部操作列固定。
4. 展開詳情：資料分組、位置與座標層級、車種共用圖示；同格普通機車 20 元／次、大型重機 30 元／小時。
5. 修改建議送出成功，顯示完成操作。
6. 完成後關閉表單與「提出修改建議」父面板，回到停車點詳情。
7. 收下詳情面板，相機停留在選取後的位置，不向下回彈。
8. 停車場各分區的車種圖示、共用／專用、費率及指引；包含重機／汽車共用卻費率不同，以及另一適用車種費率未提供的案例。

截圖為 Flutter 測試引擎的離線預覽，未載入街道圖磚；數字群聚圈與 Google Maps bitmap 共用同一個 painter，另以 fake Maps platform 驗證 bitmap 尺寸、點擊放大、單點展開與面板前後 padding 不變。測試同時檢查相機位置、面板關閉結果與輸入功能。

自檢結果：四組皆無溢出或缺字，圓圈與數字可辨識，操作狀態正確。Google 登入以平台設定測試和瀏覽器呼叫測試驗證；真實帳號的 Android／iOS 登入回跳仍需裝置驗收。
