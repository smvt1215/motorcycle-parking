### 2. 你主動送出的社群貢獻（需要登入）

- 新增停車點、修改建議：停車點名稱、座標、縣市與行政區、地址、格位與收費說明、備註文字（最多 500 字）、你附上的公告或來源網址（https）。

- 停車點座標可能來自你在選點地圖上按「移到我的位置」。這時候座標就是你當下的位置；送出與否由你決定。還沒送出前，選點時查縣市、行政區與約略門牌也會用到這個座標，見第 4 點。

### 3. 防濫用資料（送出回報、目擊、投票、地址搜尋或客服表單時）

- **網路位址雜湊**：伺服器把你的 IP 位址以帶密鑰的單向雜湊（HMAC）轉換後保存，**不保存原始 IP**，也無法從雜湊還原。
- **裝置雜湊**：App 第一次送出回報時，在手機上產生一個隨機編號（不是手機序號或廣告識別碼），伺服器同樣以 HMAC 轉換後保存。
- **Firebase App Check 驗證結果**：Android 使用 Google Play Integrity，iOS 使用 Apple App Attest，用來確認請求來自正版 App。目前只記錄結果、不擋請求。
- 每日送出次數（每帳號、每網路）。
- 地址搜尋與約略門牌查詢的次數紀錄（帳號 ID 與時間，不含座標或搜尋文字）。

### 4. 選點地圖：地址搜尋、約略門牌與縣市行政區

地址搜尋（需要登入）：

- 你在選點地圖輸入的地址、路名或路口文字，以及選點地圖目前的位置（用來優先顯示附近結果），會由我們的伺服器轉送 Google Geocoding API。
- 搜尋結果會在伺服器快取最多 30 天，快取只包含搜尋文字與約 5 公里精度的位置，不包含你的帳號。

約略門牌（需要登入，只在使用 Google 地圖時）：

- 新增停車點或建議修改位置時，選點地圖下方會顯示「約○○路○號附近」，讓你對照標記有沒有放對。
- 打開這個表單時，以及標記每次移到新位置、停住約 0.6 秒後（包括拖曳、微調、地址搜尋與按「移到我的位置」），App 會把標記的座標送到我們的伺服器。座標不先取整，就是地圖上標記的位置；按「移到我的位置」時，就是手機當下的定位。和上一次查到的位置相距不到 10 公尺時，不會再查。
- 這個請求帶著你的登入憑證，伺服器用它確認你已登入，並記一筆查詢次數（帳號 ID 與時間），和地址搜尋共用每日上限。接著伺服器只把座標轉給 Google Geocoding API 反查最近的路名與門牌號碼，不會把你的帳號、email 或 IP 交給 Google。
- 伺服器**不保存**這次的座標，也不保存查到的門牌，不做快取。門牌只顯示在你手機上的這個表單，表單關閉就消失；它不會寫進你的回報，也不會給其他使用者。
- 沒登入時不會查詢。查不到、查詢失敗或次數用完時只是不顯示門牌，不影響送出。

縣市與行政區：

- 選點時，App 會把標記的座標直接送到內政部國土測繪中心的公開查詢服務，判斷所在縣市與行政區（按「移到我的位置」時，就是你當下的位置）。這個查詢不經過我們的伺服器，也不帶你的帳號資料，但國土測繪中心的服務會看到你手機的網路位址等連線資訊。查不到時，你可以自己選縣市。

### 5. 只存在你手機上的資料（我們收不到）

- **Google 地圖**：App 用 Google Maps SDK 顯示地圖。Google 會依其說明自動蒐集 IP 位址、裝置型號與系統版本、SDK 版本、地圖操作事件、當機資訊與匿名的 SDK 識別碼，用來維運與改進 Google 服務。適用 [Google 隱私權政策](https://policies.google.com/privacy)。
- **Google Geocoding API**：地址搜尋的文字與位置、約略門牌的標記座標，都由我們的伺服器轉送。Google 看到的是我們伺服器的連線，不是你的手機，也不會收到你的帳號、email 或 IP；Google 依其隱私權政策處理收到的內容。
- **內政部國土測繪中心**：選點時，App 直接向它的公開服務查詢標記所在的縣市與行政區，會傳送標記座標，該服務也會看到你手機的網路位址等連線資訊。

## 八、不提供資料的影響

- 不登入：仍可瀏覽地圖、查規則、記錄停車位置與在手機上收藏；但不能回報、投票、目擊、地址搜尋、看約略門牌與跨裝置同步收藏。
- 不允許定位：不能顯示你的位置與附近排序，選點地圖也不能用「移到我的位置」；仍可手動移動地圖，用拖曳或地址搜尋選點。
- 約略門牌只是對照用：查不到、查詢失敗或當天次數用完，都不影響送出回報。
- 不允許通知：不會收到停車計時提醒。
- 防濫用資料（雜湊、App Check）是送出回報的必要條件，無法單獨拒絕；不同意時請不要送出回報。

## 九、安全措施

- App、網站與伺服器之間的傳輸都經 HTTPS（TLS）加密。寄到 support@ 的 email 在送達我們之前是否加密，取決於寄件端的郵件伺服器，請不要在信中寫敏感資料。

- 儲存的資料由 Supabase 以 AES-256 加密。
- 沒有任何系統能保證絕對安全；發生個資外洩時，我們會依個資法第 12 條查明後通知你。

## 十一、Cookie 與追蹤

App 不使用廣告追蹤或分析 SDK。

網站（刪除帳號頁、客服表單）本身不設定 cookie，只在你的瀏覽器使用：
